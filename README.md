# 🏨 Hotel Analysis Dashboard

## Project Overview
This Tableau dashboard analyzes hotel performance using revenue, guests, ratings, booking channels, room types, and country-wise trends.

## Tools Used
- Tableau
- Excel / CSV
- Data Visualization

## Dashboard Features
- KPI Cards
- Revenue by Booking Channel
- Revenue by Country
- Revenue Trend Over Time
- Revenue by Room Type
- Visitor Distribution
- Country-wise Ratings

## Business Insights
- Germany generated the highest revenue.
- Phone bookings produced the most revenue.
- Deluxe room type had the highest revenue contribution.
- Revenue fluctuated significantly throughout the year.
